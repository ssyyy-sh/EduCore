# Подключение сервера (Supabase)

Пока в `src/config.js` не указаны ключи Supabase, сайт работает как демо: всё хранится в браузере.
После подключения учётные записи и данные школы (оценки, посещаемость, сданные работы с файлами,
объявления, изменения учеников и учителей) хранятся на сервере и видны со всех устройств.
Права доступа проверяет база данных — подделать роль из браузера нельзя.

Сайт остаётся на GitHub Pages, Supabase — только база данных и вход.

## 1. Создать проект

1. Зайдите на https://supabase.com → **Start your project** → войдите (можно через GitHub).
2. **New project**: имя `EduFY`, придумайте пароль базы данных (сохраните его), регион — ближайший к вам.
3. Подождите 1–2 минуты, пока проект создаётся.

## 2. Создать таблицы

1. Слева **SQL Editor** → **New query**.
2. Откройте файл `supabase/setup.sql` из проекта, скопируйте **всё** содержимое, вставьте и нажмите **Run**.
3. Должно появиться `Success. No rows returned`.

Файл можно запускать повторно. **После каждого обновления EduFY запускайте его снова** — он добавит новые таблицы, ничего не удаляя.

## 3. Адрес сайта для писем

**Authentication → URL Configuration**:
- **Site URL**: `https://ssyyy-sh.github.io/EduFY/`
- **Redirect URLs** → Add URL: `https://ssyyy-sh.github.io/EduFY/`

Нужно для писем «подтвердите почту» и «сброс пароля».

## 4. Вставить ключи в проект

**Project Settings → API** (в новых версиях панели — **API Keys** и **Data API**):
- **Project URL** — вида `https://abcdxyz.supabase.co`
- **anon public** ключ (или **Publishable key**, `sb_publishable_…`)

Откройте `src/config.js` и вставьте:

```js
export const SUPABASE_URL = 'https://abcdxyz.supabase.co';
export const SUPABASE_ANON_KEY = 'ваш anon / publishable ключ';
```

Этот ключ публичный по замыслу Supabase — его можно выкладывать в GitHub.
**Никогда не вставляйте `service_role` / `secret` ключ.**

Затем:

```
npm run build:docs
git add .
git commit -m "Server"
git push
```

## 5. Стать владельцем

1. Откройте сайт → **Создать аккаунт** со своей почтой (тип «Ученик» или «Родитель»).
2. Подтвердите почту по ссылке из письма.
3. В Supabase → **SQL Editor** выполните (со своей почтой):
   ```sql
   update public.profiles set role = 'owner' where email = 'ваша@почта.uz';
   ```
4. Войдите на сайт снова — откроется «Панель владельца».

## Как дальше работают роли

- **Ученик и родитель** регистрируются сами. Пока школа их не привяжет, они видят только экран «Введите код из школы»
  (и ещё сообщения, объявления, уведомления, настройки).
- **Учитель и администратор** при самостоятельной регистрации ждут подтверждения. Владелец выбирает им роль
  в «Панели владельца» (сверху появится «Ждут подтверждения»).
- **Администратор школы** может заранее добавить учителя: «Сотрудники → Добавить учителя».
  Учитель регистрируется с этой почтой и сразу получает роль учителя и свои классы.
- **Владелец** меняет роли, блокирует учётные записи, отправляет письмо для сброса пароля,
  скачивает резервную копию и может сбросить данные школы.

## Привязка учётных записей

Каждый видит только своё — это проверяет сама база данных:
ученик — только себя, родитель — только своих детей, учитель — только свои классы.

- **Ученик / родитель.** Администратор: «Ученики» → открыть ученика → «Учётные записи»:
  - «Код для ученика» или «Код для родителя» — 8 символов, один раз, 14 дней. Человек вводит код после регистрации.
  - или «Привязать по почте» — если учётная запись уже есть, привяжется сразу; если нет — при регистрации с этой почтой.
  - Второго ребёнка родитель добавляет сам: «Настройки» → «Мои привязки» → код.
- **Учитель.** «Сотрудники» → «⋯» → «Изменить» → «Учётная запись учителя» → почта.
  Классы и предмет берутся из карточки учителя; если их поменять, доступ меняется сразу.
- Перевод ученика в другой класс автоматически переносит его доступ (и доступ родителя) на новый класс.

## Что важно знать

- Список учеников, классов и учителей школы — пока демонстрационный (Northbridge Academy).
  На сервере хранятся учётные записи, привязки и все изменения. Следующий шаг — загрузка своих списков.
- Встроенная почта Supabase отправляет ограниченное число писем в час — её хватает для проверки.
  Для большого количества регистраций подключите свою почту: **Authentication → SMTP Settings**.
  Для проверки можно выключить подтверждение почты: **Authentication → Sign In / Providers → Email → Confirm email**.
- На бесплатном тарифе неактивный проект может быть приостановлен — его можно снова включить в панели Supabase.
- Скрытый владелец из `OWNER_ACCOUNT` в `src/config.js` работает только в демо-режиме; с сервером владелец
  назначается командой из шага 5.
